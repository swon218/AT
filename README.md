# ATLAS

## 작업 및 배포 기준

- 현재 개발·커밋·푸시 기준은 `main`입니다. 기본 작업 디렉터리는 `D:\AT`입니다.
- 미완료 실험실 일봉 전환(`118aa19`, `ac85f2a`)은 역적용했고, 선별 배포 브랜치의 최신 대시보드 변경(`9bccfca`)은 `main`에 통합했습니다. 과거 커밋 기록은 보존합니다.
- `codex/dashboard-orders-only`는 과거 선별 배포 기록입니다. 더 이상 이 브랜치나 해당 worktree를 기본 작업 위치로 사용하지 않습니다.
- 기존의 ‘main을 배포하지 말라’는 선별 배포 문서는 과거 기록입니다. 현재 기준은 [main 복구 및 배포 지침](deploy/MAIN_RESTORE_HERMES.md)입니다.
- 실험실은 전환 전 코드와 기존 21시·03시 수집 방식을 유지합니다. 코드 복구가 운영 DB의 과거 품질 문제 복구 완료를 뜻하지는 않습니다.

`main` 푸시 후 Vercel의 Production 자동 배포 결과를 확인합니다. VPS 코드 적용은 프런트 자동 배포와 별개이며 해당 작업의 서버 변경 여부에 따라 진행합니다.
