# 헤르메스 전달문 — 조건 검색 차트 이동

ATLAS 저장소 `https://github.com/swon218/AT`의 `main`에서 커밋 메시지가 `조건 검색 차트 이동`인 변경의 프런트엔드 배포를 확인해 주세요.

## 변경 사항

- 조건 검색 결과의 `차트` 버튼을 클릭하면 실험실 대신 주식 주문 탭으로 이동합니다.
- 클릭한 결과의 종목코드·종목명·시장을 상단 종목검색과 같은 선택 처리에 전달합니다. 예: 삼성전자 결과 클릭 → 주식 주문의 삼성전자 `005930` 선택.
- 주식 주문의 기존 시세·캔들 조회 경로를 사용합니다. 검색 결과의 확정 일봉 수치를 현재 시세로 전달하지 않습니다.
- `조건 값`은 결과표 전체 아래에 조건별 실제 값, 기준값, 충족 여부를 펼치는 기존 기능입니다. 돌파 조건은 이전 값도 표시합니다. 이 기능은 변경하지 않았습니다.

## 배포

프런트엔드 변경이므로 VPS의 Node/FastAPI 재시작, 환경 변수 수정, SQL 적용, 일봉 재수집은 필요하지 않습니다.

1. Vercel이 GitHub `main`을 배포한다면 해당 커밋을 포함한 프로덕션 배포 성공을 확인하세요.
2. VPS에서 프런트엔드 정적 파일도 직접 제공하는 구성일 때만 실제 저장소 경로에서 아래 명령을 순서대로 실행하고 기존 방식으로 새 `dist`를 배포하세요. 작업 트리가 깨끗한지 먼저 확인하고, 단계가 실패하면 중단하세요. 운영 변경이나 설정을 덮어쓰지 마세요.

```bash
git status --short
git pull --ff-only origin main
git log -1 --oneline
npm ci
npm run build
```

## 화면 확인

1. 조건 검색에서 결과가 나오는 조건으로 검색하세요.
2. 삼성전자(`005930`) 결과가 있으면 `차트` 클릭 후 주식 주문 탭과 종목명·코드가 맞는지 확인하세요. 없으면 검색된 다른 종목으로 확인하세요.
3. 조건 검색으로 돌아와 다른 종목의 `차트`를 클릭했을 때 주식 주문 종목이 새로 바뀌는지 확인하세요.
4. 실제 운영 시세와 캔들이 선택 종목으로 조회되는지 확인하세요. 로컬에서는 테스트 응답으로 종목 전달과 화면 이동을 검증했으며, 실제 증권사 캔들 조회는 이번 검증 범위에 포함하지 않았습니다.
5. `조건 값` 클릭 시 결과표 전체 아래의 `종목명 · 조건별 실제 값` 영역을 확인하세요. 결과가 많으면 아래로 스크롤해야 합니다.

로컬 검증: `npm run build`, `node --test tests/screener.test.js` 2/2 통과. Chrome 테스트 응답으로 삼성전자 → 주식 주문, 이어서 SK하이닉스 → 주식 주문 및 조건 값 상세 표시를 확인했습니다.

보고할 내용: 반영 커밋, 프런트엔드 배포 상태, 클릭한 종목과 주문 화면 종목 일치 여부, 실제 시세·캔들 표시 여부, 미확인 항목.
