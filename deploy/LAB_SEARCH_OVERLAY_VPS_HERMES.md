# VPS 헤르메스 전달문 — 실험실 검색 개선

ATLAS 저장소 `https://github.com/swon218/AT`의 `main`에 올라온 `실험실 검색 개선` 커밋의 프런트엔드 배포를 확인해 주세요.

실험실 자동완성 검색 목록 위에 차트의 시가·고가·저가·종가가 겹쳐 보이는 문제를 수정했습니다. 차트 내부 표시를 별도의 표시 영역으로 묶어 검색 목록 뒤에 두었습니다. 검색 목록이 덮는 영역에는 차트 정보가 보이지 않아야 합니다.

## 배포

- 이번 변경은 CSS만 수정합니다. API 재시작·환경 변수 변경·SQL 적용·일봉 재수집은 필요하지 않습니다.
- Vercel이 GitHub `main`을 배포한다면 해당 커밋의 프로덕션 배포 성공을 확인하세요. 이전 프런트엔드가 캐시돼 있으면 새로고침 후 다시 확인하세요.
- VPS에서 직접 프런트엔드를 서비스하는 구성이라면 실제 저장소 경로에서 아래 명령을 순서대로 실행하고, 기존 방식으로 새 `dist`를 배포하세요. 각 단계가 실패하면 다음 단계로 진행하지 마세요.

```bash
git status --short
git pull --ff-only origin main
git log -1 --oneline
npm ci
npm run build
```

운영 측 로컬 변경을 덮어쓰지 말고, 기존 `.env`, 실험실 DB와 수집 설정을 유지하세요.

## 화면 확인

1. 실험실에서 일봉 차트가 표시된 상태로 `sk하이`를 입력하세요. 검색 결과와 도움말 위로 시가·고가·저가·종가가 보이지 않아야 합니다.
2. 한 글자 검색처럼 결과가 많아 목록이 거래량·보조지표 영역까지 내려와도 목록이 아래 차트 정보를 가려야 합니다. 검색 결과 목록 스크롤도 확인하세요.
3. 방향키·Enter 또는 마우스로 종목을 선택하면 목록이 닫히고 선택한 종목의 차트가 정상적으로 표시되는지 확인하세요. Esc로 닫은 뒤에도 차트 정보가 정상적으로 보여야 합니다.
