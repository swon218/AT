# 대시보드 시장 데이터 조사 (2026-09-29)

이번 구현은 시장 순위 / 관심종목 카드의 프런트엔드 배치만 변경한다.
기존 `realtime`, `rising`, `falling`, `volume`, `surge`, `favorites` 요청과
종목 선택 시 차트를 바꾸는 동작은 유지한다. 지수·환율 API는 아직 연결하지 않는다.

## 키움 공식 명세 확인 결과

출처: [키움 REST API 공식 명세 JSON](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/kiwoom/_data/kiwoom_api_spec.json).
공식 포털의 GitHub 링크로 연결된 Kiwoom-Securities 저장소에서 확인했다.
아래 내용은 명세 확인 결과이며 실제 계정 토큰으로 호출한 결과는 아니다.

| 화면에 필요한 데이터 | 공식 API | 확인 내용 |
| --- | --- | --- |
| 코스피·코스닥 현재 지수, 전일 대비, 등락률 | `ka20001` 업종현재가요청, `POST /api/dostk/sect` | 코스피 `mrkt_tp=0`, `inds_cd=001`; 코스닥 `mrkt_tp=1`, `inds_cd=101`. `cur_prc`, `pred_pre`, `flu_rt` 제공 |
| 주요 지수 장중 차트 | `ka20005` 업종분봉조회요청, `POST /api/dostk/chart` | 위 업종 코드와 `tic_scope` 사용. 1·3·5·10·15·30·45·60분 지원, 기준일 `base_dt` |
| 주요 지수 기간별 차트 | `ka20006` 일봉, `ka20007` 주봉, `ka20008` 월봉 | 동일한 업종 코드로 조회. 화면의 1주·1개월·3개월·1년 구간은 일봉을 기간에 맞게 표시하는 방식으로 구성 가능 |
| 장중 지수 실시간 갱신 | `0J` 업종지수 | REST 조회와 별도로 WebSocket `/api/dostk/websocket` 구독 가능 |
| 원/달러 환율 | `ust31301` 환율 조회, `POST /api/us/exchange` | 미국주식 > 환전 영역. 환전 방향 `exch_tp=1` 원화→달러, `2` 달러→원화. 매수·매도·적용 환율 및 우대율 반환 |

차트 지수 값은 명세에서 **소수점을 제거한 100배 값**으로 설명한다.
차트 API 응답의 해당 OHLC 필드에 나누기 100 처리가 필요하다.
현재가 API와 모든 실시간 필드에 동일 변환을 일괄 적용하지 말고 API별 단위와 실제 응답을 검증해야 한다.

`ust31301`은 **증권사 환전 적용 환율**이다. 이미지의 시장 원/달러 환율과 동일하다고 볼 수 없다.
이 응답에는 전일 대비·등락률·환율 시계열이 없다. 따라서 환율 숫자를 표시한다면
‘키움 환전 적용 환율’처럼 기준을 명시해야 한다. 이미지처럼 시장 환율의 등락과 작은 차트까지
보여주려면 시장 환율 시계열을 제공하는 별도 출처를 검토해야 한다.
현재 사용 중인 국내주식 계정·토큰의 미국주식 API 이용 가능 여부도 실제 연결 단계에서 확인해야 한다.

## 기존 코드에서 확인한 제한

- 현재 관심종목 요청은 `server/rankings.js`에서 빈 배열을 반환한다. 이번에는 해당 동작을 유지한다.
  카드의 별 표시는 이미지에 맞춘 장식이며 관심종목 등록·해제 기능을 새로 추가한 것은 아니다.
- 기존 백엔드가 거래량을 `1.2만` 같은 축약 문자열로 보내므로 새 거래량 열에도 그 값을 그대로 표시한다.
  이미지처럼 축약하지 않은 거래량 숫자로 바꾸려면 별도 데이터 계약 변경이 필요하다.
- `거래량 급증` 탭은 기존과 같이 등락률 자리에서 급증률을 표시한다. 이미지의 거래대금 순위로 바꾸지 않는다.
