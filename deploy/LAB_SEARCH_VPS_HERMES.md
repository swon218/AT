# VPS 헤르메스 전달문 — 실험실 검색

ATLAS 저장소 `https://github.com/swon218/AT`의 `main`에 올라온 `실험실 검색` 커밋을 확인하고 운영 웹의 프런트엔드에 반영해 주세요.

## 변경 내용

- 실험실의 종목 검색 입력창과 종목 선택 드롭다운을 공통 자동완성 검색창 하나로 통합했습니다.
- `s`, `삼` 같은 한 글자부터 아래에 결과가 표시되고, 스크롤·위/아래 방향키·Enter 또는 마우스 클릭으로 종목을 선택합니다. Esc로 닫습니다.
- 선택하면 해당 종목의 저장된 일봉 차트와 실험실 데이터가 로딩됩니다. 종목 변경 시 검증 기간을 선택한 데이터 범위로 초기화하며 지표·매매 조건·비용 설정은 유지합니다.
- 검색 결과에 일봉 개수·미수집·오류 격리 일수를 표시합니다. 데이터가 전혀 없는 종목은 선택할 수 없고, 격리 일봉이 있는 종목은 기존 품질 경고와 백테스트 차단 정책을 유지합니다.
- 검색 UI는 다른 탭과 공유하지만 실험실의 데이터 공급원은 기존 `/api/public/lab/symbols`, `/api/public/lab/candles?symbol=...`입니다. 실험실에서 글자를 입력할 때마다 검색 API를 호출하거나 개인 증권사 키를 조회하지 않습니다.

## 반영 절차

이번 변경은 프런트엔드 중심이며 API 경로·DB 스키마·환경 변수 변경이 없습니다. 새 검색창 때문에 일봉을 재수집하거나 SQLite를 다시 만들 필요가 없습니다. 기존 실험실 DB와 수집 서비스 설정을 유지하세요.

Vercel이 GitHub `main`에서 배포되도록 연결돼 있다면 `실험실 검색` 커밋의 프로덕션 배포 성공 여부를 확인하세요. GitHub push 성공만으로 운영 웹 반영 완료라고 보고하지 마세요.

VPS의 저장소도 동기화한다면 실제 `atlas-api.service`의 `WorkingDirectory`를 확인하고, 그 경로에서 다음을 실행하세요. 로컬 변경이 있으면 덮어쓰지 말고 먼저 확인하고, 각 명령이 실패하면 다음 단계로 진행하지 마세요.

```bash
git status --short
git pull --ff-only origin main
git log -1 --oneline
npm ci
npm run test:search
npm run test:strategies
npm run build
```

이번 UI 반영만을 위해 API 재시작은 필수가 아닙니다. 앞선 `검색 개선` 커밋의 API 배포가 아직 안 됐다면 `deploy/STOCK_SEARCH_VPS_HERMES.md`에 따라 그 변경도 함께 반영하세요. VPS가 직접 프런트엔드를 서비스한다면 기존 방식으로 새 `dist`를 배포하고, Vercel을 사용하면 Vercel 배포를 확인하세요.

## 운영 검증

1. 실험실 탭에서 종목 입력창과 별도의 선택창 두 개가 아니라 자동완성 검색창 하나와 새로고침 버튼만 표시되는지 확인하세요.
2. DB에 수집된 종목 기준으로 `s → sk → sk하이닉스`, `삼`, `005930`을 검색하세요. 결과는 입력 즉시 갱신되고 부분일치·대소문자 무시가 작동해야 합니다.
3. 위/아래 방향키로 이동한 뒤 Enter를 누르거나 마우스로 클릭하면 목록이 닫히고 선택한 종목명·코드·일봉 차트·데이터 기간이 표시되는지 확인하세요. 결과가 많으면 스크롤로 50개 이후도 선택할 수 있어야 합니다.
4. 미수집 종목은 비활성화되고 방향키가 건너뛰는지 확인하세요. DB에 해당 사례가 없으면 이 항목은 미확인으로 보고하세요. 오류 격리 데이터는 오류 표시와 기존 품질 검증을 유지해야 합니다.
5. 두 종목을 빠르게 연속 선택해도 마지막 선택의 데이터가 표시되어야 합니다. 일봉 개수와 시작/종료일이 해당 종목에 맞는지 확인하세요.
6. 대시보드·주식 주문 탭에서도 기존 공통 종목 검색과 선택이 정상 작동하는지 확인하세요.

실험실 검색은 VPS에 저장된 목록을 대상으로 합니다. 검색되지 않는 종목이 있다면 기존 수집 상태를 먼저 확인하세요. API 응답에 없는 일봉을 만들어 표시하지 마세요.

보고할 내용: 반영 커밋, Vercel 또는 프런트 배포 상태, 실험실 키보드/마우스 선택 결과, 선택 후 일봉 표시 여부, 다른 탭 검색 확인 결과, 미확인 항목.
