# ATLAS AI 에이전트 채팅 공간

이번 변경은 React 프런트엔드의 채팅 UI만 추가한다. LLM, FastAPI, 에이전트용 Node.js API, 증권사 주문/조회 도구는 연결하지 않는다.

## 포함 기능

- 실험실과 자산 현황 사이의 AI 에이전트 메뉴.
- 대화 목록, 검색, 새 대화, 삭제 확인, 질문 입력/보관을 제공하는 전용 화면.
- 첨부 로봇 이미지로 여는 작은 채팅창. 클릭으로 열기/접기, 드래그/방향키 이동, X로 숨기기.
- 전용 화면의 로봇 표시 스위치와 작게 열기 버튼으로 복원.
- 작은 창과 전용 화면이 같은 대화와 작성 중인 글을 공유한다.
- 메뉴 이동과 새로고침 후 복원. 대화/로봇 설정은 계정별 브라우저 localStorage에 보관한다.
- AI 미연결 상태를 표시하며 질문 보관 시 분석 답변을 생성하지 않는다. 다른 기기와 동기화하지 않는다.

## 배포 범위

웹 배포에만 반영하면 된다. 기존 Vercel Git 배포를 사용하는 경우 이 변경이 해당 저장소/브랜치에 반영된 뒤 정상 빌드/배포 완료를 확인한다. 이 문서 작성 자체로 커밋/푸시/운영 배포가 완료되었다는 의미는 아니다.

VPS의 패키지 설치, 환경변수/API 키 설정, FastAPI 서비스 생성, 포트/프록시 변경, 데이터베이스 SQL 실행, 기존 API 서비스 재시작은 필요 없다.

## VPS 헤르메스에게 전달할 지시문

```text
ATLAS에 AI 에이전트용 채팅 화면을 추가했지만 이번 범위는 React 프런트엔드 UI뿐이다.
이번 변경으로 VPS에서 실행할 추가 작업은 없다.
FastAPI, LLM 연결, 에이전트 API, API 키, 신규 포트/프록시, DB 테이블을 아직 만들지 않는다.
기존 atlas-api 서비스와 뉴스·시세·일봉 수집 작업은 현재 운영 상태로 유지한다.
이 UI 변경을 위해 패키지를 설치하거나 기존 서비스를 재시작하지 않는다.
웹은 기존 프런트엔드 배포 경로에서 반영한다. 에이전트 서버 구축은 이후 별도 요청으로 진행한다.
```

## UI 확인

1. AI 에이전트 메뉴가 실험실과 자산 현황 사이에 표시되는지 확인한다.
2. 로봇 클릭/재클릭, 드래그 후 클릭이 구분되는지 확인한다.
3. 작은 창에서 입력/보관하고 넓게 보기로 이동해 같은 대화/초안이 표시되는지 확인한다.
4. 대시보드·실험실·자산 현황으로 이동해 상태가 유지되는지 확인한다.
5. X로 숨긴 후 전용 화면의 로봇 표시 스위치 또는 작게 열기로 복원한다.
6. 새 대화, 검색, 대화 전환, 삭제 확인을 점검한다.
7. 새로고침 후 복원, 로그인/로그아웃 시 계정별 보관 범위를 확인한다.
8. 모바일에서는 내부 대화 목록을 접고 입력창 및 로봇이 화면 안에 표시되는지 확인한다.

로컬 검증: `npm run test:agent`, `npm run build`.
