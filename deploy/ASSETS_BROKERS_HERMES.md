# 헤르메스 전달문 — 자산현황 증권사추가

ATLAS 저장소 `https://github.com/swon218/AT`의 `main`에 올라온 `자산현황 증권사추가` 커밋의 프런트엔드 배포를 확인해 주세요.

이번 변경은 웹 화면과 기존 개인 계좌 조회 API 연결만 수정합니다. VPS 서버 코드, 의존성, SQL, 환경 변수 변경이 없으므로 이 커밋 때문에 `atlas-api.service`를 재시작하거나 SQL을 실행할 필요는 없습니다. 기존 VPS API와 사용자별 암호화 API 설정을 그대로 사용합니다.

## 배포 확인

1. GitHub `main`에 연결된 Vercel 배포가 해당 커밋으로 성공했는지 확인해 주세요. 실패했다면 빌드 로그를 확인하고 보고해 주세요.
2. 운영 웹을 새로고침하여 자산 현황 탭에 키움증권·토스증권·NH투자증권·KB증권 버튼 4개가 표시되는지 확인해 주세요.
3. VPS 저장소까지 같은 커밋으로 맞추려면 실제 서비스 저장소 경로에서 `git status --short`를 확인한 뒤 로컬 변경이 없을 때 `git pull --ff-only origin main`만 실행해 주세요. 이 화면 변경만 반영하려는 경우 API 재시작은 필요 없습니다.

## 읽기 전용 확인

- 비로그인: 버튼은 비활성 상태이고 자산 금액은 `—`로 표시되며 개인 계좌 조회 요청을 보내지 않아야 합니다.
- 로그인: 기본적으로 4개 증권사를 선택합니다. 1~4개를 선택할 수 있고 마지막 1개는 해제할 수 없습니다.
- 선택한 증권사만 자산·평가손익·주문가능금액과 보유종목에 반영됩니다. 동일 종목도 증권사별로 구분합니다.
- API가 없는 증권사는 `API 미연결`, 조회 오류는 `조회 실패`로 표시합니다. 일부 증권사만 조회되거나 특정 금액이 제공되지 않으면 `부분 합계`와 조회 건수를 표시하며 모르는 금액을 0원으로 채우지 않습니다.
- NH 계좌가 여러 개라면 조회 계좌를 선택한 후 합계에 반영합니다. 이번 화면은 NH의 선택한 계좌를 조회하며, NH의 모든 계좌를 자동 합산하지 않습니다.
- 로그아웃하거나 다른 사용자로 로그인하면 이전 사용자의 자산이 남지 않아야 합니다. API 설정을 변경하면 기존 결과를 비우고 새 설정으로 조회합니다.
- 실제 개인 계좌 조회는 사용자가 로그인한 웹에서 확인해 주세요. 자산 조회 결과의 검증을 위해 주문 API를 호출할 필요는 없습니다.

운영 API에 `/api/account/kiwoom/summary`, `/api/account/toss/summary`, `/api/account/nh/summary`, `/api/account/kb/summary`가 이미 있어야 합니다. NH/KB의 기존 배포가 누락되어 404가 발생한다면 `deploy/BROKERS_VPS_HERMES.md`의 선행 배포 여부를 확인하고 누락 사항을 보고해 주세요. 이번 변경만을 위해 새 키나 관리자 키를 추가할 필요는 없습니다.

보고할 내용: 프런트엔드 배포 커밋과 성공 여부, 비로그인 화면 확인 결과, 로그인 후 선택·합산 확인 결과, 개인 API 연결 부족 등으로 검증하지 못한 증권사. 계좌번호·API 키·잔고 등 개인 정보는 보고에 노출하지 마세요.
