# 종목 알림 독립 탭 검증

2026-11-16, 실제 App + `node tests/themeBrowserHarness.mjs` 격리 Chrome 검증입니다. 모든 계정·API·대화·규칙·발송 이력은 모의 데이터입니다.

- 메뉴 순서: 조건 검색 → 종목 알림 → AI 에이전트. 제목·활성 메뉴 일치, 접힌 사이드바에서 접근 가능한 이름 유지.
- 실제 구형 `?agent=alerts#alert-history` 링크가 `?page=alerts#alert-history`로 replace되어 게스트 안내를 표시. 로그인 후 기존 발송 이력 확인.
- 메뉴 이동 후 뒤로/앞으로 및 새로고침에서 화면·URL 복원.
- AI는 분석·매매 두 항목만 표시. 방향키로 두 탭 순환하고 기존 매매 화면 표시.
- 모의 분석 질문의 현재가 200,000원 초안이 종목 알림으로 전달됨. 기존 관심종목에 없는 경우 확인 카드의 예 → 관심종목 추가 → 새 페이지 미저장 초안 표시.
- 알림 화면에는 AlertAgentPanel 1개, AgentWorkspace 0개, agent-mode-tabs 0개. 분석/알림 구현을 숨겨 동시에 마운트하지 않음.
- 카카오 설정 모달을 열었다 닫고, AI 탭 왕복 및 새로고침 후에도 200,000원 미저장 입력 유지.
- 기존 저장 조건·발송 이력과 알림 관리창 표시, 도움말 Space/Escape 동작 확인. 수정·취소·저장 실행은 하지 않음.
- 계정 A 알림 GET을 지연시킨 뒤 계정 B로 변경. 이전 계정 규칙·이력이 섞이지 않고 B의 신규 초안만 표시. 로그아웃 후 개인 조건/이력 제거.
- API 집계에서 알림 GET만 발생하고 `POST /api/agent/alerts` 0건. 모의 대화 요청·관심종목 확인 POST와 알림 활성화 POST를 구분.
- 1366×768 다크·라이트, 390×844 모바일에서 페이지 가로 넘침 없음. 좁은 화면 표는 내부 가로 스크롤, 모바일 메뉴 선택 시 닫힘.

검증 하네스는 `.js`/확장자 없는 import 사이에도 모의 인증을 공유하도록 수정했습니다. 운영 인증 코드는 변경하지 않았습니다.

미검증: 운영 로그인 회원의 실제 규칙 저장·수정·취소, 실제 카카오/모델 호출·발송. 이 작업에서는 서버/worker/DB/모델 로직과 환경설정을 변경하지 않았습니다.
