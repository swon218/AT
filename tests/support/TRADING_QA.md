# 매매 에이전트 V1 검증 범위 (2026-11-16)

실제 증권사 API, 운영 회원 데이터, 실주문/취소/정정, 유료 모델, 카카오 발송을 사용하지 않았습니다.

## 자동 검사

- gateway: 공식 스키마 형태의 고정 응답, 실제 공통 주문내역 normalizer, 개인 KRX 시각/현금/보유/주문/체결, 선택 계좌, 삭제 epoch, write 직전 재검사, 비재시도와 모호한 결과.
- engine: 기존 실험실 evaluator와 동일한 확정 일봉 신호, 고정/전체 현금, 특별 개장, 늦은 진입 방지, 부분/역순/중복 체결, 평균가와 소유분 손익, 정지/취소 중 늦은 체결, 명시적 관리 중단, 기존 보유 인수, 외부 충돌, API 삭제, 두 worker, prepared/sending crash 복구.
- SQL: PGlite에서 실제 기존 전략/관심종목 스키마 + 전체 신규 SQL 적용/재적용, RLS·권한, 소유권/revision, 오래된 요청, 현금 예약/dispatch, stop과 아직 position에 반영되지 않은 체결 경쟁, 실제 엔진↔RPC↔SQL 전체 흐름.
- PostgreSQL 17: 새 격리 로컬 클러스터에서 서로 다른 psql 세션의 SKIP LOCKED, 현금 예약 경쟁, dispatch 경쟁, commit 후 실제 DB backend 강제 종료와 새 lease 복구, 직접 쓰기 거부를 확인했습니다. 클러스터를 정상 종료·삭제했습니다. `tests/tradingPostgres.test.js`는 명시적인 테스트 바이너리 환경값이 없는 일반 실행에서는 skip합니다. 운영 DB URL/비밀번호를 받지 않으며 실제 data_directory까지 검사합니다.
- API/driver: 회원 인증/Origin, 내부 loopback+전용 secret, 공개 프록시 경계, 저장과 시작 분리, 미리보기/시작 재검증, 중복 시작, 삭제 경쟁, 개인 차트와 safe DTO.
- 최초 전체 서버 검사에서 로컬 socket EACCES 1건이 있었고 해당 8건 재실행은 통과했습니다. 전송 직전 훅까지 반영한 최종 전체 서버 검사는 로컬 통신 허용 환경에서 **357/357 통과**했습니다. 자동매매·키움 transport·실제 SQL·차트 표현 집중 검사는 **69/69 통과**, 별도 네이티브 PostgreSQL 동시성 검사는 **1/1 통과**했습니다.
- 토큰 발급과 유량 대기 뒤 실제 HTTP 직전 일회용 SQL 전송 허가를 확인합니다. 그 사이 정지·관심종목 삭제·관리중단·lease 교체가 있으면 전송하지 않습니다. 이미 소비한 허가는 재사용하지 않으며 결과 불명은 예약을 유지합니다.

## 실제 Chrome, 격리 UI

실제 제품 컴포넌트를 사용하는 `tests/support/trading.html`, Vite `vite.trading.config.js`에서 모의 API만 주입했습니다. 이 엔트리는 제품 앱에서 참조하지 않으며 프로덕션 빌드에 포함되지 않습니다.

- 1366×768, 390×844 CSS viewport, 다크·라이트.
- 관심종목 행 선택/전략·수량·최초 동작 변경/선택 행 저장. 저장과 시작이 구분되고 미시작 차트도 선택 가능.
- 실행 최초 오른쪽 빈 안내, 개별 시작 확인(계좌/주문 방식/최초 매수/정지 정책).
- 보유 평균가 200,000원 선, 익절/손절과 성과, 개인 차트의 15분 전환.
- 완료 거래 자동 표시, 대기 중 기본 숨김, 거래 이력 표시와 개별 거래 선택 복원.
- 정지 확인의 기본 보호 유지, Escape 취소와 트리거 버튼 포커스 복원, ArrowRight 탭 이동.
- 서버 LIVE 비활성 안내/버튼 차단, 로그아웃 후 개인 실행 UI 제거.
- 모바일/데스크톱 전체 페이지 가로 넘침 없음, 표는 카드 내부에서 스크롤. Canvas와 평균가 선도 실제 공통 테마 저장소 변경에 반응.

OS 배율/실기기 터치, 운영 개인키/증권사 모의투자/실계좌, 장중 실제 체결·API 호출량과 장애 복구는 미검증입니다. 브라우저 종료와 무관한 실행은 서버 엔진/영속 RPC 테스트로 검증했으며 운영 서버에서 실제 자동매매를 시작한 것은 아닙니다.
